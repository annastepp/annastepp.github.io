Predicting Reading Difficulty Risk in Early Readers Using Machine Learning on Phoneme Blending Drill Performance

University of Florida · 2026 - Ongoing

This project proposes developing an ML-based early warning system that uses session-level blending drill data to identify students at risk of dyslexia.

Automating Word Ladder Generation Using Computational Methods

University of Florida · 2025-2026

Word ladders let early readers practice decoding one sound at a time, but existing digital versions are fixed in content. This project generates them automatically for each lesson so teachers can match practice to what they're actually teaching.
